# AndroidでPWAとして使う手順

このアプリはPWA（Progressive Web App）化されています。
無料サービスにアップして、AndroidのChromeから「ホーム画面に追加」すると
ネイティブアプリのようにアイコンから起動できます。

おすすめは **Netlify Drop**（最速）または **GitHub Pages**（更新が楽）です。

---

## 方法A：Netlify Drop（最速・5分）

1. ブラウザで <https://app.netlify.com/drop> を開く
2. このフォルダ（`フラッシュカードv3`）を**まるごとドラッグ＆ドロップ**
3. 数秒で `https://◯◯◯-◯◯◯.netlify.app/` のような **公開URL** が発行される
4. アカウント登録（無料、メアドだけでOK）するとURLを保持できる
5. AndroidのChromeでそのURLを開く
6. 右上のメニュー（︙）→「ホーム画面に追加」→「インストール」を選ぶ
7. 端末のホーム画面に**アイコン**ができる。タップすると全画面で起動

更新するとき：同じページから新しいフォルダを再度ドラッグするだけ
（**URLは保持**される）。Android側は次回起動時に自動で新バージョンに切替。

---

## 方法B：GitHub Pages（git で更新したい人向け）

1. GitHubで新しいリポジトリを作る（プライベートでもOK、ただしPagesは公開URL）
2. このフォルダを `git init && git add . && git commit && git push`
3. リポジトリの Settings → Pages → Source を **`main` / root** に設定
4. 数十秒で `https://ユーザー名.github.io/リポジトリ名/` で公開される
5. AndroidのChromeで開き、メニュー →「ホーム画面に追加」

更新するとき：ローカルで変更 → `git push` → 自動デプロイ。
Android側は再起動で自動更新。

---

## インストール後の使い方

- ホーム画面のアイコンをタップ → **全画面**で起動（ブラウザのアドレスバーなし）
- **オフライン対応**：一度開いたあとは機内モードでも使える
  （サービスワーカーが裏でキャッシュしているため）
- カードを追加して再デプロイすると、次回起動時に自動で反映される

---

## ローカルで先に動作確認したい場合（任意）

PWA は HTTPS または localhost でしか動かないので、ファイルを直接ダブルクリックでは
サービスワーカーが登録されません。簡易サーバーを立てると確認できます。

Windows（PowerShell）：
```
cd "C:\Users\sucre\OneDrive\デスクトップ\フラッシュカードv3"
python -m http.server 8080
```
→ ブラウザで `http://localhost:8080/` を開く

スマホで同じ wifi 内から確認したい場合は、PCの IPアドレスで
`http://192.168.x.x:8080/` のように開く（PWA としては動くが、
ホーム画面追加は HTTPS が必要なため Netlify か GitHub Pages にアップしてから行う）。

## トラブルシューティング

**カードを増やしたのに反映されない**
→ サービスワーカーがキャッシュを返している。`sw.js` の冒頭にある
   `CACHE_VERSION = "v1.0.0"` を `"v1.0.1"` などに上げると、
   次回起動時にキャッシュを破棄して読み直す。
   （Netlify/GitHub Pagesに再デプロイした時、ファイルが更新されていれば
   通常は自動で取り直すが、強制的に切り替えたい時はバージョンを上げる）

**「ホーム画面に追加」が出てこない**
→ Chrome の右上メニューから「アプリをインストール」または「ホーム画面に追加」を選ぶ。
   出てこないときは数秒待つ（サービスワーカーの登録待ち）か、ページを再読み込み。
